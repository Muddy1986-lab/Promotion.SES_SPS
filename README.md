# Samsung Promo Hub — Update 12 Oct 2026

เว็บไซต์สรุปโปรโมชั่น Samsung โดยใช้ภาพตารางโปรโมชั่นฉบับล่าสุดที่ได้รับในบทสนทนา

## ไฟล์
- `index.html` — เว็บไซต์ Responsive พร้อมปุ่มขยาย/ย่อภาพ
- `assets/latest-promotion-12-oct-2026.jpg` — ภาพโปรโมชั่นต้นฉบับ

## เปิดใช้งาน
เปิด `index.html` ในเว็บเบราว์เซอร์ได้ทันที

## เผยแพร่บน GitHub Pages
1. อัปโหลด `index.html` และโฟลเดอร์ `assets` ไปยัง root ของ repository
2. เปิด Settings → Pages
3. เลือก Deploy from a branch, branch `main`, folder `/(root)` แล้วกด Save

หมายเหตุ: หน้าเว็บใช้ภาพโปรโมชั่นต้นฉบับเพื่อรักษาความถูกต้องของตัวเลขและเงื่อนไข ให้ตรวจสอบกับประกาศล่าสุดของร้านก่อนเสนอขาย
