# Samsung Promotion Hub — SESTH · SPSTH

เว็บไซต์ Static พร้อมใช้งานบน GitHub Pages มีหน้ารวมโปรโมชั่นและหน้า Admin สำหรับจัดการรายการสินค้า

## Deploy บน GitHub Pages
1. สร้าง GitHub repository ใหม่ และอัปโหลดไฟล์/โฟลเดอร์ทั้งหมดในโปรเจกต์นี้ (อย่าอัปโหลดเฉพาะไฟล์ ZIP)
2. ไปที่ **Settings → Pages**
3. เลือก **Deploy from a branch**, เลือก branch `main` และ folder `/ (root)` แล้วกด Save
4. รอ GitHub สร้างเว็บไซต์ แล้วเปิด URL ที่แสดงในหน้า Pages

## วิธีอัปเดตโปรโมชั่น
1. เปิด `.../admin.html` บนเว็บไซต์
2. เพิ่ม/แก้ไข/ลบสินค้า และแก้ช่วงแคมเปญ/เงื่อนไข
3. กด **ส่งออก JSON สำหรับ GitHub** เพื่อดาวน์โหลด `promotions.json`
4. ใน GitHub เปิด `data/promotions.json` → Edit (ดินสอ) → วางเนื้อหาจากไฟล์ที่ส่งออก → Commit changes
5. เมื่อ Pages deploy เสร็จ ทุกคนที่มีลิงก์จะเห็นข้อมูลที่อัปเดต

## ข้อจำกัดสำคัญ
GitHub Pages เป็น Static hosting ดังนั้น Admin ตัวอย่างนี้ไม่มีระบบล็อกอินและไม่สามารถบันทึกไฟล์กลับ GitHub โดยตรงได้ การแก้ไขในหน้า Admin จะอยู่ในหน่วยความจำของเบราว์เซอร์จนกว่าจะส่งออก JSON และอัปเดตไฟล์ใน repository เอง หากต้องการแก้ไขออนไลน์แล้วให้ข้อมูลเปลี่ยนสำหรับทุกคนทันที ต้องเพิ่ม backend/database และระบบยืนยันตัวตน เช่น Supabase/Firebase หรือ GitHub OAuth + API

## ข้อมูลราคา
รายการสินค้าและราคาที่ให้มาเป็น **ข้อมูลตัวอย่างเพื่อสาธิตหน้าเว็บ** อ้างอิงแนวทางจากภาพที่แนบ ไม่ใช่การยืนยันราคาโปรโมชั่นอย่างเป็นทางการ กรุณาตรวจสอบราคา รุ่น ความจุ ของแถม และเงื่อนไขล่าสุดกับทีมผู้ดูแลก่อนเผยแพร่จริง

## โครงสร้าง
- `index.html` — หน้าโปรโมชั่น
- `admin.html` — หน้าจัดการข้อมูล
- `styles.css` — Responsive UI
- `app.js` — ค้นหา กรอง และแสดงรายการสินค้า
- `admin.js` — CRUD ในหน้า Admin และ export/import JSON/CSV
- `data/promotions.json` — ข้อมูลโปรโมชั่นที่เผยแพร่
- `assets/` — ภาพอ้างอิงที่แนบมา
